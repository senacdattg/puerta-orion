✨ EJEMPLO DE USO
═══════════════════════════════════════════════════════════════════════════════

1️⃣  CREAR SESIÓN (Primera vez):
   
   POST http://localhost:5000/api/sesiones
   {
     "nombre": "Mañana",
     "descripcion": "Sesión matutina 8:00 AM - 12:00 PM"
   }

2️⃣  CREAR TIPO DE EVENTO (Primera vez):

   POST http://localhost:5000/api/tipos-evento
   {
     "nombre": "Entrenamiento",
     "descripcion": "Sesiones de práctica regular"
   }

3️⃣  CREAR EVENTO (Desde el frontend):

   {
     "titulo": "Entrenamiento de Fútbol",
     "fecha": "2024-12-01",
     "horaInicio": "14:00",
     "horaFin": "16:00",
     "lugar": "Cancha Principal",
     "descripcion": "Entrenamiento de técnica y táctica",
     "tipo": "Entrenamiento"
   }

   → El servicio mapea automáticamente y envía:

   POST http://localhost:5000/api/eventos
   {
     "nombre": "Entrenamiento de Fútbol",
     "fecha_evento": "2024-12-01",
     "hora_inicio": "14:00",
     "hora_fin": "16:00",
     "lugar": "Cancha Principal",
     "descripcion": "Entrenamiento de técnica y táctica",
     "id_categoria": 1,
     "id_tipo_evento": 1,
     "id_sesion": 1
   }

⚙️ VALIDACIONES IMPLEMENTADAS
═══════════════════════════════════════════════════════════════════════════════

BACKEND:
✅ nombre: mínimo 3 caracteres (requerido)
✅ fecha_evento: formato YYYY-MM-DD (requerido)
✅ hora_inicio: formato HH:MM o HH:MM:SS (requerido)
✅ hora_fin: formato HH:MM o HH:MM:SS (requerido)
✅ hora_fin > hora_inicio (validación cruzada)
✅ lugar: mínimo 3 caracteres (requerido)
✅ descripcion: opcional
✅ Existencia de relaciones (categoría, tipo, sesión)
