## 1. INTRODUCCIÓN

Este documento presenta los requisitos no funcionales del Sistema Administrativo para el Club Deportivo Puerta de Orión. A diferencia de los requisitos funcionales que describen qué debe hacer el sistema, los requisitos no funcionales definen cómo debe hacerlo, estableciendo características y condiciones que garantizan eficiencia, seguridad y rendimiento.

**Total de Requisitos No Funcionales Documentados: 6**

---

## 2. REQUISITOS DE SEGURIDAD

**RNF-001** **Autenticación y Recuperación de Cuenta**: El sistema debe implementar autenticación mediante tipo de documento, número de documento y contraseña, con la opción de recuperación de cuenta mediante correo electrónico.

**RNF-002** **Control de Acceso Basado en Roles y Permisos**: El sistema debe establecer roles y permisos para restringir el acceso a datos sensibles según el perfil del usuario, garantizando que cada usuario solo pueda acceder a la información y funcionalidades correspondientes a su rol.

---

## 3. REQUISITOS DE RENDIMIENTO

**RNF-003** **Soporte de Múltiples Usuarios Simultáneos**: El sistema debe ser capaz de soportar múltiples usuarios conectados simultáneamente, garantizando un rendimiento óptimo y evitando la saturación del sistema.

**RNF-004** **Tiempo de Respuesta**: El sistema debe tener un tiempo de respuesta inferior a 2 segundos para ejecutar consultas y generar informes, asegurando una experiencia de usuario fluida y eficiente.

---

## 4. REQUISITOS DE COMPATIBILIDAD

**RNF-005** **Compatibilidad con Navegadores**: El sistema debe garantizar compatibilidad con diversos navegadores web actualizados que utilicen las tecnologías implementadas en el proyecto, asegurando que los usuarios puedan acceder al sistema desde diferentes entornos.

---

## 5. REQUISITOS DE DISPONIBILIDAD

**RNF-006** **Disponibilidad del Sistema**: El sistema debe asegurar la disponibilidad la mayor parte del tiempo, exceptuando los períodos programados para mantenimiento, garantizando que los usuarios puedan acceder a los servicios cuando los necesiten.

El sistema implementa 7 requisitos no funcionales esenciales organizados en 6 categorías principales: seguridad, rendimiento, compatibilidad, disponibilidad y cumplimiento legal. Estos requisitos garantizan que el sistema sea seguro, eficiente, accesible y cumpla con las normativas aplicables.
